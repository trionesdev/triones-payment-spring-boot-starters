# TrionesDev - 支付通道SDK Spring Boot 自动装配

## 模块
[微信支付 Spring Boot Starter](triones-wechatpay-spring-boot-starter/readme.md) 微信支付SpringBoot自动装配

[微信支付 Spring Boot Starter Rest](triones-wechatpay-spring-boot-starter-rest/readme.md) 微信支付SpringBoot自动装配，带回调接口

## 使用
添加依赖管理
```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>com.trionesdev.payment</groupId>
            <artifactId>triones-payment-dependencies</artifactId>
            <version>版本号</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```
